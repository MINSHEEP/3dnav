操作指南：开始、停止与恢复控制权

开始遥控
① 手柄三档开关回到 1 档。② 按 9，等“SDK 已取得控制权”。③ 按 Y 站立，等“站立 / 0xB102”。④ 按 4，等“可以遥控 / 0xB104”。已经站立可跳过 Y；已可遥控则不必重复切换。

移动与普通停止
W/S 前后，A/D 横移（最高 0.2 m/s），Q/E 原地转向。按住移动，松开停止；0 或 X 请求零速度。转向时不同时平移。零速度不等于趴下，也不保证取消已发给机器人的站立动作。

站立、趴下不是任何时候都能用
先停止移动，确认已取得控制权、没有锁定且上一个动作已完成。Y 请求固定站立，U 请求趴下；是否接受还取决于机器人实际状态。站立完成后不会自动进入 MOVE；从 MOVE 回到固定站立可先停止，再按 Y。站立和进入 MOVE 要求已知电量高于 15%。充电、故障或动作过渡期间不要反复切换。

R 什么时候用？
仅在停车锁定、SDK 故障或无法重新取得控制权时使用；先确认机器狗已安全停稳。R 会重启璇玑 SDK 会话，不是普通停止键，不会自动申请控制权、站立或恢复运动。等“reset 已确认”后再按 9。连接或复位过程中不要重复按 R。遥控会话已停用时先刷新页面。

突然失去控制权（ctrl:0）
松开方向键，查看日志并确认手柄回到 1 档。没有锁定：按 9 等确认。有锁定：R → 等复位完成 → 9 → 等取得控制权。再根据姿态执行 Y → 等站立完成 → 4。若已有 0xB102 可跳过 Y；若复位后虽显示 MOVE 却未放行，先回固定站立再进入 MOVE。反复失败时停止重试，保留第一条报错，检查网络或重新应用本体。

T 与普通停止不同
T/1 请求阻尼并锁定运动，会改变关节支撑；不是保持站立的刹车。没有 SDK 控制权时，网页不能保证停止机器狗，请使用现场手柄处置。

建图与导航
仍使用主机雷达。独立遥控页会停止建图和导航节点；需要建图时请进入建图页操作。导航维持前进和原地转向，禁止横移、倒车。先校准雷达外参、碰撞轮廓及速度，再在设置页确认导航参数；不能仅为解除限制而勾选确认。
