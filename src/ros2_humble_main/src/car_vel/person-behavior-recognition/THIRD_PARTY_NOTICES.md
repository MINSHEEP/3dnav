# Third-party sources / 第三方来源

This repository integrates or adapts the following projects. This CPU deployment archive contains complete model binaries and the required pinned PaddleDetection source files; Git LFS is not required. models_manifest.json records historical model provenance, while assets/runtime_assets.json lists the models actually included.

- **PaddleDetection / PP-Human**: <https://github.com/PaddlePaddle/PaddleDetection>, pinned commit `b25522a0f4bde8c80603f3ba5e3472059972e3b5`. Its Apache-2.0 license text is retained in [licenses/Apache-2.0.txt](licenses/Apache-2.0.txt). Upstream provenance is recorded in `environment/upstream_source.json`; the downloader preserves the source license.
- **zhahoi/yolov8-pose-fall-detection**: <https://github.com/zhahoi/yolov8-pose-fall-detection>. Geometric fall rules were adapted through the local rule port, then changed for observability checks, tracking, bounded temporal confirmation, projected lying posture and recovery. The [upstream license](https://github.com/zhahoi/yolov8-pose-fall-detection/blob/main/LICENSE) is Apache-2.0. This project does not claim the upstream rule implementation as wholly original.
- **Ultralytics YOLOv8**: official YOLOv8m-pose weights, exported with Ultralytics 8.3.228. The [versioned upstream license](https://github.com/ultralytics/ultralytics/blob/v8.3.228/LICENSE) is AGPL-3.0. The weights and training/export dependency are not relicensed by the ROS package's metadata. Source URLs and export settings are in `models_manifest.json`.
- **Ultralytics YOLO26**: optional official `yolo26s-pose.pt` from the [v8.4.0 assets release](https://github.com/ultralytics/assets/releases/download/v8.4.0/yolo26s-pose.pt), exported using isolated Ultralytics 8.4.198 tooling. Original FP32 weights and COCO17 keypoint ordering are retained. A batch-1 equivalent row gather allows the export to run on OpenVINO 2024.6 without updating the runtime environment. Source hashes, settings and reference-output checks are recorded in `output_inference/yolo26s_pose_openvino_fp32/export.json`. The [Ultralytics AGPL-3.0 license](https://github.com/ultralytics/ultralytics/blob/v8.4.198/LICENSE) continues to apply.
- **PaddleVideo ppTSM**: <https://github.com/PaddlePaddle/PaddleVideo>. The fighting model uses the official `PaddleVideo-release2.3/ppTSM_fight.zip` asset linked in the model manifest.

第三方代码、模型和依赖各自保留其许可证及来源声明。仓库中的 Apache-2.0 文本用于保留相关第三方许可，不表示全部模型与依赖统一改为 Apache-2.0，也不为它们授予额外许可。

CPU exports use OpenVINO mixed INT8 with floating-point output heads. Quantization provenance is recorded beside each model in `quantization.json`. Conversion and quantization do not replace the upstream licenses. `assets/runtime_assets.json` lists the default CPU assets; `assets/runtime_assets_gpu.json` lists the retained FP32 profile.
