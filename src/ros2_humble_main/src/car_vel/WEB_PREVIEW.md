# 网页低带宽预览（2026-10-22）

本次只优化发送给浏览器的显示数据，保留相机采集、YOLO推理与取证、热SDK测温、
完整点云建图/保存、定位/地形网格、Nav2参数和失联停车门禁。适用于星玑和钢镚的网页
显示，不修改任何本体SDK、步态或控制能力。不是5G公网延迟保证。

## 使用方法

设置 → 网页传输预览，选择档位并保存，然后在停稳、停止遥控操作后重新进入业务页。
配置保存在当前浏览器/站点，不会重启后台，不改变其他浏览器，也不会自动刷新运行中页面。

| 档位 | 视频最大尺寸/帧率/JPEG质量 | 全局显示点云 |
|---|---|---|
| 5G远程（默认） | 640×360 / 5 FPS / 55 | 15 cm体素，最多2万点，每3秒最多一帧 |
| 局域网高清 | 1280×720 / 15 FPS / 82 | 5 cm体素，最多12万点，每秒最多一帧 |

视频保持长宽比，不放大小图；例如256×192热图保留该尺寸。JPEG不是固定码率，复杂
画面仍可能产生更大流量。局域网档也经过共享预览编码，并不是无损原始视频。
全局点云周期为限频上限，源未发布新帧时不伪造更新；不保证固定帧率。

遥控、USB相机、巡检页右上角可选普通、热成像、双路、关闭；5G默认只开一路。
建图只有普通视频，仍须使用原摄像头开关开启。双路/多页面/多客户端流量会累加。
当前标签页的预览选择通过sessionStorage保留；切页关闭旧连接不停止后台识别和测温。
显式“打开当前帧”和巡检取证仍可使用原始图片，这是按需的一次性请求。

隐藏标签页、退出页面、关闭预览会断开HTTP画面；切回可见且预览允许时重新连接。
地形导航/巡检切换到二维显示时关闭三维点云连接，建图按原视图互斥订阅。
页面重新显示不会恢复旧运动命令；遥控原有停止、会话与人工急停逻辑不变。

## 后端隔离

- camera_web新增`/api/preview/stream?source=raw|yolo|thermal&profile=remote|lan`，以及
  `/api/preview/frame.jpg`单帧接口。所有浏览器普通/本体、YOLO标注、热图统一使用预览出口。
  原`/api/stream`继续供本机YOLO读取；原快照、原始热图及证据接口不降画质。
- 每个来源/档位共享一个编码缓存，最多6个条目；按需刷新，无浏览器时不额外编码。
  慢连接不持有编码锁，不积压旧帧；发送缓冲和写超时有界。断线会释放原视频连接槽。
- 新`web_cloud_preview`节点对实时显示流按需消费原话题。原话题：
  `/global_mapping_cloud`、`/global_localization_map`、`/cloud_mapping_dynamic`、
  `/octomap_point_cloud_centers`。输出为`/web_preview/{remote,lan}`加原话题名。
  实时流没有预览消费者时解绑输入。静态`/global_localization_map`例外：常驻
  RELIABLE + TRANSIENT_LOCAL输入，接收地图加载时保存的最新一帧，即使浏览器晚打开。
  不改原点云发布、地图密度、地形网格输入或保存接口。
- 动态显示点云最多2 Hz；只有里程计新鲜且frame一致时，裁剪到机器人附近15米。
  坐标不一致时不做任意位置裁剪，但仍限制点数。单帧原始点数据另外限制5G为512KiB、
  局域网为4MiB；base64和协议封装会增加实际传输量。所有原始每点字段/字节、header坐标
  和采集时刻保留；无效坐标不会变成地面证据。点云显示身份继续匹配原地图status。
- 实时显示点云话题使用独立WebSocket；状态、服务、控制仍用原控制连接。
  导航/巡检的已保存地图已改为下述完整PCD独立HTTP，不再使用抽稀点云话题。
  完整地图加载失败不静默回退到简化图，也不因此放宽三维预检。
- 三维选点仍提交map坐标到原地面/路线预检接口。抽稀图只是显示，不代替原地图或
  地形网格判断，也不证明稀疏区域安全。

## 部署

同步完整修改到小电脑。先停稳机器狗、停止任务、建图先保存，再正常关闭旧后台。
无需更改路由器或重新编译海康/机器人SDK，本次无需重编LIO或地形包：

```bash
cd /home/a/3dnav
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select car_vel
source /home/a/3dnav/install/setup.bash
```

构建成功后按原方式只启动一套主后台，再Ctrl+F5刷新网页。新节点由
launch_manager.launch.py启动，不要另外重复启动一套机器人后台。依赖sensor_msgs、
nav_msgs和python3-numpy已加入包清单；相机预览复用现有相机Python环境中的cv2/numpy。

保持机器狗静止，在已加载ROS环境的终端分别执行只读核对：

```bash
ros2 node list
```

应包含`/web_cloud_preview`。在浏览器打开建图三维视图后，再单独执行：

```bash
timeout 10s ros2 topic hz /web_preview/remote/global_mapping_cloud
```

输出频率不高于约0.33 Hz；没有建图或没有源点云时没有数据是正常的。
终端订阅本身也会构成预览需求，核对结束后退出该命令。浏览器开发者工具Network中
视频应请求`/api/preview/stream`而不是原始`/api/stream`。

## 网络验收

保持静止，依次各测一分钟：全部预览关、仅普通、仅热图、仅点云、视频加点云。
记录发送速率、CPU、ping和实际图像延迟，并标记切换时间；不要通过移动机器人测试
卡顿。如果空载仍有秒级延迟，再检查5G信号、Tailscale直连/中继及公网链路。
若降载后仍不能满足需求，再单独评估H.264/WebRTC，不把降低失联保护作为优化方法。

离线测试使用假ROS/SDK、合成JPEG/点云和本机HTTP/浏览器拦截。它们验证代码隔离与
生命周期，不等同于目标Linux构建、5G带宽实测或机器人实机安全验收。

## 已保存PCD的全部点（导航、巡检）

- 建图页面继续实时降载，保存行为不改；导航/巡检只从独立只读HTTP读取原保存PCD。
  不改ICP的120000点显示上限或地形算法输入，也不更改保存地图的体素参数。
- 全部点指保存文件中现存的全部点，不是恢复保存前已滤掉/体素合并的雷达采样。
  传输原文件全部字节和字段，无抽稀、空间裁剪、点数截断。PCD坐标按元数据map使用，
  不把VIEWPOINT额外变换一次。浏览器支持ASCII、binary、binary_compressed（LZF）。
- 下载前核对当前map_name/load_id/ICP stamp，校验同名定位元数据、点数、文件长度、
  SHA256；下载后浏览器再次验SHA256（普通HTTP无WebCrypto时有本地实现）。旧版本、
  切图或退出页面后的回复丢弃，不交给选点流程。没有匹配身份时拒绝读图。
  网页只需当前map_name/load_id即可请求清单；精确stamp由后台可靠订阅取得并绑定返回，
  不依赖网页自己收到一次性的ROS身份消息。文件下载仍必须携带这个已确认stamp。
- 导航/巡检绘制全部有限XYZ点，页面列出文件总点数、绘制点数和非有限坐标记录数。
  NaN/Infinity没有可绘制的位置，不会冒充地面证据。完整地图仅辅助选点，仍由原后端
  检查地面/路径、定位质量与本体能力，不会因为地图更密就自动允许通过。
- 传输按需一次，内存和IndexedDB缓存最近一份、以SHA256为文件版本；切换导航/巡检时
  先取得新身份清单，相同文件可重用已校验字节。浏览器配额不足仅禁用磁盘缓存，不删点。
  隐藏页面/切2D/退出会取消下载，返回可恢复。HTTP数据不占ROS控制WebSocket。
- 初次下载5G流量和时间会增加；显示进度。网络/身份暂未就绪最多五次尝试，30秒没有
  进展会明确报错。文件上限128MiB、声明400万点、解码体积256MiB；超限、解析失败或
  显存不足时明确失败并保持三维选点只读，绝不自动抽稀来伪装完整显示。

完整文件端口默认8769，由已有web_cloud_preview进程启动；不要另开第二套后台。
仅允许读取当前已确认地图目录的文件，无上传/删除/动作接口。Origin必须与机器人
主机名相同；在可信局域网/Tailscale内使用，不要把此只读地图端口直接开放到公网。
前端需能访问机器人8769端口；HTTPS页面需按现有部署配置反向代理，当前内置HTTP不提供TLS。
