# 二维＋三维联动擦除与地面保护

## 部署

同步完整的 `lzp_interface`、`lzp_service`、`car_vel` 三个源码包到小电脑。
保持机器人停止，结束所有任务并停止旧后台，不能只更新网页。
本次沿用既有EditMapCloud接口，只新增`preview_linked`动作和JSON结果字段，没有新增srv字段。
若此前已构建该接口，本次只需同步并构建`lzp_service car_vel`；首次安装则按下面三包构建。

```bash
cd /home/a/3dnav
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select lzp_interface lzp_service car_vel
source /home/a/3dnav/install/setup.bash
```

按原方式只启动一套后台，浏览器Ctrl+F5。不改变雷达标定、本体SDK、2D导航参数或实时避障。

## 清理步骤

1. 停止机器人和所有巡检/导航任务，进入“修图”，确认核心停止成功，打开待编辑地图。
2. 不开启联动时，普通“障碍/可通行/未知”画笔仍然只编辑PGM；先保存或撤销这些修改，再勾选“二维＋三维联动擦除”。
3. 用上方“画笔拖拽”或“矩形框选”累积选区。黄色像素是实际选区，不是笔画间的外接矩形；可“撤销一笔选区”或“清空联动选区”。选择不会立即改变PGM或PCD。只对保存图原本为黑色的像素联动，不删除白格/未知格内的点。
   默认范围为“联动擦除：仅原二维黑格”；若需要原先不依赖二维黑格的三维清理，可选择“原三维工具：整个选区”。原工具同样保留地面和台阶保护，但不支持纯二维误黑纠正；切换范围后必须重新预览。
4. 设置相对当地地面的高度下/上限，默认0.15～0.8m，不是地图绝对Z。点“预览待删除点”。红色为待删点，蓝色为选区内**所有高度的保留点**，并非所设高度的截取图。两图分别适应视角；每组最多显示12000点（抽样），真实删除按全部原始点计算。
5. 查看待删点数、二维清理格数、未删除原因及相对高度范围。只有地面的误黑格，可能显示“待删0点、二维可清理若干格”：这会保留原PCD全部字节，只修正通过保护检查的二维黑格。若两项都为0，只能查看原因，不会生成提交令牌。
6. 核对现场确为误障碍及保留地面、墙体、实际障碍后，勾选确认，再点“确认清理并备份”。同一XY的地面、头顶点不会无条件整列删除；PCD也用于定位，不能因为看着杂乱就清空。
7. 保存后退出修图，进入导航重新启动核心、加载该地图、设置初始定位，先预览路线再决定是否启动。旧路线点不会自动修改，旧地图身份/定位/预览不能直接续用。

停止确认失败、地图正在加载/任务活动、普通2D修改未保存、预览过期或文件改变，都不允许提交。
预览仅120秒有效，改变高度/选区/地图使页面预览失效；确认令牌只能消费一次。离开页面、重新打开或切换模式/地图前，会提醒未保存的联动选区。

## 地面保护和范围限制

- 必须已有新版 `ground_measured` 实测地面层，confidence至少0.35；该格还须存在距地面±0.08m内的真实点。不从未知区域插值“补地面”。这是编辑工具条件，不改变运行时地形置信度配置。
- 只允许几何已确认平缓的格：坡度绝对值不超过12°、台阶指标不超过0.08m。缺失/NaN、明显台阶和陡坡格保留，防止把另一层落脚面误删。
- 删除高度下限至少0.15m，上限不超过3m；地面附近和范围外点保持原记录。单次最多10000像素/25m²，不超过原PCD的10%，剩余点至少2000。
- 只有保留了实测地面、清理后该地形格内无0.12～1.5m的剩余碰撞点时，才把选区内原黑格改为自由；二维未知格不会强制变自由。联动模式允许地面误黑格只改二维，不要求先删除PCD点。旧`preview`动作仍要求实际删除过点才联动清二维。
- 清理后按原地形生成参数重新生成terrain.npz，更新PCD点数/长度/摘要及配套定位元数据；原始字段类型（含intensity等）保持不变。支持binary/ascii的COUNT=1记录，压缩/无效格式明确拒绝，不静默丢字段。

未删除原因按互斥顺序统计，合计等于选区保留点数：非原二维黑格、地面未确认（含低置信度）、台阶/坡度保护（含NaN）、缺少真实地面点、地面保留、删除高度之外。后两项使用相对地面高度。
这些条件可能使部分区域“没有可提交修改”，应根据原因核对、补录实测地面或缩小范围，不应靠取消保护强制清空。
保存地图清理不会屏蔽实时雷达看到的真实障碍，也不证明狭窄通道足以通过机器狗。

## 备份与恢复

每次保存前备份原来的PGM、YAML、PCD、terrain.npz、localization.yaml五件套，目录为：

```text
/home/a/3dnav/src/ros2_humble_main/src/navigation/robot_navigation2/pcdmaps/
  .cloud-edit-backups/<地图名>/<操作ID>/
```

日志会显示具体备份路径。页面“恢复最近三维清理”可恢复最近一次清理前的整套文件，备份不会被自动删除。
若清理后另行修改/重建了地图，恢复会拒绝覆盖，需先人工核对；不要直接混拷某一个文件。

编辑和地图保存通过跨进程文件锁互斥；编辑持锁期间阻止启动建图/导航。安装前写入待完成标记，加载器与完整PCD读取均拒绝未完成版本。
普通安装异常回滚；若回滚不完整或程序中断，保留标记和备份，可在核心停止后使用恢复入口。恢复中断也可再次恢复。

## 巡检页面排版

巡检专属头部把导航和状态分两行，导航文字不再挤成竖排；工具栏自然换行，图例回到正常文档流；左右视频约束尺寸、长提示换行、相机按钮两列。
已离线验证1890、1366、1024和390像素宽度；任务、视频、告警和导航接口功能不变。

## 验证范围

算法/文件事务用临时合成地图测试：地面保留、PCD字段无损、过期/改图拒绝、五件套摘要、故障回滚、备份恢复、恢复中断重试和互斥。
浏览器通过全网络拦截测试实际修图/巡检页面，不访问机器人；JSON作为测试文档适配器，不代替目标Linux环境的PyYAML和ROS接口构建验收。
没有对用户真实地图执行删除，不能据离线测试宣称现场误障碍已清除或导航已恢复。
