# 园区级室内外全地形导航基础

当前版本支持在同一张连续全局地图内，建图保存后直接对平地、草地/碎石、粗糙地面、安全缓坡和安全低台阶进行自动导航，不再要求逐段手工标注连接段。它仍不是任意空间中的体素级三维飞行规划，而是“三维点云定位 + 2.5D地形代价全局规划 + 实时点云复核 + Nav2底盘执行”。连续楼梯、跨地图/跨独立定位区域、负障碍和超限地形继续失败关闭，并保留人工标定连接段作为高风险例外。自2026-10-21起，只有已确认星玑的3D同图自动监督默认不再以综合置信度低于0.70单独停车；未知地形和其他检查仍保留，详见文末限定范围与恢复方法。

## 在设置页选择 2D/3D 巡检导航

“设置”页现在提供两个全局选项，默认使用更保守的“3D地形增强导航”。选择会原子保存到 `~/.ros/robot_navigation/navigation_mode.json`，ROS2 后台或小电脑重启后继续沿用。

- **2D地图导航（`map_2d`）**：`/terrain_costmap` 适配器直接转发当前 `/map` 给 Nav2，路线目标仍检查当前地图和 AMCL 定位新鲜度，但暂停地形网格融合、地形连通性预检、自动地形步态和地形限速。急停、速度所有权、Nav2 静态层/膨胀层、实时 `/scan` 障碍层、特殊地形点和跨层路线阻止规则仍然生效，因此它不是“关闭避障”。
- **3D地形增强导航（`terrain_3d`）**：继续使用当前的 2.5D 地形融合成本地图、目标地形预检、实时地形监督、自动步态和地形限速。界面简称 3D，但它不是体素空间自由规划。

两种模式都保留现有地图加载、三维点云定位与初始位置精修流程。模式只改变规划/地形策略，不会在 2D 模式下退回较弱的定位来源。

巡检任务创建时会冻结并记录当时的模式，暂停、继续、路线恢复和后台重启接管都沿用该值。巡检、路线、单点或园区导航运行期间，`/navigation/set_mode` 会拒绝改变模式；必须先停止活动任务。当前状态通过瞬态本地话题 `/navigation/mode` 发布，路线状态的 `navigation_mode` 字段和巡检任务/报告 JSON 也会保留该值。

巡检页面订阅 Nav2 的真实 `/plan` 显示全局规划路径。2D 模式显示原始 XY 路径；3D 模式显示由匹配地形网格补高后的展示路径。`/navigation/global_path` 只用于显示，不会反馈给控制器或改变 Nav2 正在执行的计划；任务停止、地图切换或连接断开时页面会清除旧路径。

## 在设置页调整障碍膨胀半径

“设置”页可把全局与局部 Nav2 代价地图的障碍膨胀半径统一调整为 0.30–1.50 米，默认和推荐值为 0.55 米。半径越大，规划路径离墙面、家具和激光检测到的障碍越远；同时也越容易判定狭窄通道不可通过。低于 0.30 米会接近当前机身半宽和 footprint padding 的安全边界，因此后端直接拒绝。

设置原子保存到 `~/.ros/robot_navigation/inflation_radius.json`。Nav2 尚未启动时可以先保存；启动后路线管理器通过 `/global_costmap/global_costmap/set_parameters` 与 `/local_costmap/local_costmap/set_parameters` 更新两处 `inflation_layer.inflation_radius`。状态话题 `/navigation/inflation_radius` 只有在两处都确认当前版本后才发布 `applied=true`；任一服务不可用、拒绝或超时时保持待应用并自动重试，不会把部分成功冒充为已生效。

巡检、路线、单点或园区导航运行期间，`/navigation/set_inflation_radius` 拒绝更改半径。Nav2 重启后，后端会重新应用持久值；两处代价地图尚未同步时，新的导航目标和等待恢复的目标都不会下发。该设置只改变 inflation layer，不会关闭静态地图、实时激光障碍层、急停、速度所有权或三维地形门禁。

## 地图与动态点云各自用途

建图模式现在同时维护三种地图和一条不持久化的动态诊断点云：

- `/global_mapping_cloud`：与保存的定位 PCD 同源，保留通过连续多帧稳定确认的全高度范围点，不经过 OctoMap 的障碍高度裁剪。为保护 CPU、内存和网络，页面预览默认每 2 秒最多发布 12 万点；保存 PCD 仍使用完整持久快照。
- `/cloud_mapping_dynamic`：尚未通过时间稳定性确认的动态/候选体素，仅用于建图页诊断，不写入 PCD、OctoMap 或二维投影。它不是唯一的安全避障输入。
- `/octomap_point_cloud_centers`：由已通过稳定确认的 `/cloud_mapping_filtered` 生成的三维障碍占据图，只保留地面清除与碰撞高度范围，适合检查障碍层，不代表完整全局三维地图。
- `/projected_map`：OctoMap 的二维占据投影，供现有 Nav2、地图编辑和楼层内平面导航使用。

建图页面默认显示全局三维地图，并可切换“动态障碍点云”“障碍占据图”和“二维投影”。实时导航避障仍从未被静态过滤器修改的 `/cloud_registered` 独立生成安全高度窗内的 `/scan`；候选点不会因为被排除在持久地图外而从实时避障链消失。

动态判断不使用固定高度直接删除，而是使用有界时序体素的连续观测次数和持续时间。默认 OctoMap 链需连续观测至少 8 次且持续 1.5 秒，当前定位 PCD 配置需连续 6 个采样观测且跨越至少 15 个雷达帧；`protected` 模式的可靠地面使用 3 个采样观测、至少 6 帧的确认门槛。楼梯、坡面、路缘和固定结构在持续可见后会转为静态；短时行人和车辆保持为候选。已经长时间静止并通过阈值的物体仍可能被当作静态，因此该第一阶段不能替代语义跟踪或射线级动态占据清除。

### 2026-10-20：动态过滤开启时保留重访静态点

全局点云与定位 PCD 的累积器已修复重访旧区域时掉点的问题：`protected` 和 `strict` 模式下，已通过各自门槛的静态体素保留确认状态及质心统计，不再因观测中断而重新降为候选；`protected` 已确认地面也不会因为回程视角稀疏、当前帧不再满足地面邻域条件而消失。未确认候选仍须连续观测，间隔超限仍重新计数，过期候选仍清理。无需改为 `bypass` 或降低确认门槛。

这项修改针对静态地图保留，不新增“物体消失”检测；长时间静止且已确认的物体后来被搬走，仍需后续射线级清除或重新建图。网页预览超过 12 万点后的抽稀也仍存在，它与本次已修复的完整地图快照掉点不同。

将源码同步到小电脑后，先停止建图及运动，在 `/home/a/3dnav` 重新编译 `small_point_lio`，重新加载 `install/setup.bash` 并重启建图。选择启用动态过滤的 `protected` 模式，在同一平地区域完成“建图→离开→返回补扫→保存并重载”核对。已保存地图中缺失的点不会由此次修复凭空恢复，需要重新采集补齐。Windows 离线核心复现与 14 项累积器测试通过；Linux ROS2 构建及现场验证仍待执行。

导航模式加载一张地图后，地图切换服务会先校验同名 PCD、定位元数据、大小、点数和 SHA-256。新保存的地图还包含同事务生成的 `<地图名>.terrain.npz`，该文件与 PCD 的 SHA-256 绑定；声明了地形工件但文件缺失、损坏或不匹配时，会在 Nav2 加载二维图之前拒绝导航。旧版地图没有 `terrain_grid` 元数据时仍可兼容，但会明确记录“从 PCD 运行时重建地形”，不会把二维投影静默冒充三维地形。

地形导航页可在“二维导航图”和“全局三维地图”之间切换；NDT/GICP 仍使用完整保存 PCD 的局部 ROI，页面只接收最多 12 万点的预览。规划节点优先直接加载经过校验的持久化 2.5D 地形网格，不再因为 `/current_map_info` 的周期公告每秒重复读取 PCD 和重算地形。它使用的是保存时的完整全局定位点云所派生的数据，不是 OctoMap 障碍裁剪点云。

## 2.5D 地形网格

建图启动文件会运行 `terrain_grid_node`，从 `/global_mapping_cloud` 低频生成 `/terrain_grid`；统一保存时则从不受 12 万点网页预览上限影响的完整定位 PCD 生成并持久化同一格式的地形工件。默认分辨率为 0.25 m，最多 40 万格，并输出：

- 高程 `elevation`
- 坡度 `slope_deg`
- 粗糙度 `roughness_m`
- 邻格最大高差 `step_height_m`
- 观测置信度 `confidence`
- 实测地面证据 `ground_measured`（1 为真实低位地面簇，0 为未知或推断面）
- 保守通行代价 `traversal_cost`（未知 -1、可通行 0、谨慎 60、特殊模式 90、禁止 100）

未知或观测不足的格子保持禁止推断，不会被自动填成平地。`/terrain_grid/status` 向页面提供尺寸、分辨率、已知格和禁止格统计。点云中“没有回波”不能可靠地区分沟槽、悬崖与未观测区域，因此负障碍仍需基于实时射线可见性或专用传感器判断，不能只凭全局点云缺失自动放行。

## 已实现

- 路线点支持 `x/y/z/yaw`、园区区域、楼层、地形类型、执行模式、特殊通道和限速。
- 旧 SQLite 路线数据库自动增加字段，旧路线默认是 `z=0`、`flat`、`normal`。
- `/evaluate_terrain` 根据坡度、横坡、台阶、沟槽、粗糙度、通行宽度、置信度、湿滑和负障碍返回普通、谨慎、特殊模式或禁止通行。
- `/plan_campus_route` 在园区区域、建筑入口、楼层、楼梯和坡道之间选择可通行拓扑路线。
- `/get_campus_topology` 向上位机提供区域、楼层和通道配置，避免前端复制拓扑数据。
- `/manage_campus_topology` 以修订号管理完整园区配置，后端执行结构校验、任务互锁和同目录原子替换；两个浏览器页面不能静默覆盖对方的新版本。
- `/terrain_observation` 从实时注册点云生成机器人前方走廊的坡度、横坡、台阶、粗糙度、间隙、净宽和置信度。消息缺失、过期、未知或超出能力上限时，连接段执行失败关闭。
- `/automatic_terrain_navigation/status`、`safe` 和 `speed_limit` 将实时地形判断送到最终速度仲裁器。进入坡道/低障碍/粗糙模式需连续3帧确认，恢复普通模式需连续5帧确认；切换中、观测超过0.75秒或模式服务不可用时Nav2输出为零。
- 自动全局规划使用双向保守边界：坡度不超过18°、邻格台阶不超过12 cm。达到更高风险等级的格仍按致命障碍处理，不会因为机器狗曾爬过17 cm就自动放行。
- 当前二维路线执行器会拒绝特殊模式、特殊地形、非零高程和路线内楼层切换，避免把跨层目标错误地压成 `z=0` 交给 Nav2。

## 上位机页面

打开 `navigation.html` 后，可以直接加载建图页统一保存的地图、设置初始位姿和目标，并查看自动地形导航的实时安全、运动模式、限速与停车原因。Nav2 每次生成或更新全局规划时，页面会同时显示一条实线规划路径：二维视图显示精确 XY，三维视图使用已保存地形补足高度；保存的巡检路线点仍以另一种虚线样式显示，避免把“路线任务”与“当前实际规划”混淆。路径桥只做显示抽稀和高程投影，不会修改控制器正在执行的原始 `/plan`。

### 星玑 3D 模式下在点云中操作多点路线与巡检点

1. 在“设置”页选择星玑本体和“3D地形增强导航”，在导航页加载地图、完成当前地图定位。确认三维点云、地图加载标识和机器人状态均正常；点云图先切换到“俯视”。
2. 在导航页选择“多点导航”，新建或编辑路线。直接在俯视点云图拖拽增加路线点或重设选中的路线点及朝向；候选位置须通过当前地图的地面检查后才写入草稿。路线列表仍可删除和调整顺序，点云编号会同步。完成后保存路线。
3. 点击“预览整条路径（不运动）”。后台逐段规划并检查每段路径、所有目标点及有限循环的回程段；预览线只是 Nav2 规划路径的地面投影，不是四足落脚轨迹。检查无误后须在预览有效期内另外点击启动。修改路线、地图、定位、本体状态或循环设置后，应重新预览。
4. 在巡检页选同一张地图和已保存路线。3D 模式自动显示点云路线编号；点击编号可切换该点是否为检测点，侧栏仍可设置检测内容和图片保存选项。若要新增或挪动路线点，可用“在三维导航页编辑路线”进入上述编辑流程，保存后返回巡检页重新选择路线。
5. 巡检页按需使用“设置初始位置”→“俯视选点”拖拽→“确认三维初始点”。随后点击“预览巡检路线（不运动）”，检查路径，再单独点击“开始任务”。巡检多轮执行时仍会逐段重新校验，不把一次预览当作永久通行许可。

上述三维选点只在已确认的星玑 `terrain_3d` 模式开放；原有 `map_2d` 的二维地图操作保持不变。3D 路线须使用有限循环，暂不允许持续无限循环或巡检往返方向交替；路线预览最多检查 32 个连续目标点，超出时请拆分路线。未知地面、特殊地形和不满足预检条件的路径会拒绝启动。即使预览通过，保存地图也不能证明近场没有后来出现的坑洞或障碍，自动上下楼梯仍未开放。

打开 `campus_navigation.html` 则可管理自动地形总开关、允许自动切换的粗糙/低障碍/坡道模式，以及确有必要的跨地图或高风险连接段。

页面会明确区分以下三类状态：

- 配置拓扑：默认保存在 `~/.ros/robot_navigation/campus_topology.json`，首次使用自动创建。浏览器只编辑草稿，后端保存成功后才成为规划事实来源。
- 实时感知：页面显示 `/terrain_observation` 和 `/terrain_costmap/status` 的健康状态，不会把配置拓扑冒充实时点云；实时数据超过 0.75 秒即按过期处理。
- 路线执行：连接段必须有双端点、实地标定标志、足够地形置信度、已选择的验收运动模式和持续实时观测。同图自动地形段仍由 Nav2 执行。

地形导航页的路线点已使用受控地形和运动模式选项；巡检页会保留并显示区域、楼层、高程和特殊地形信息。

## 保守能力包络

以下值是软件默认安全上限，不是机器狗硬件极限：

| 项目 | 默认值 |
|---|---:|
| 上台阶 | 0.15 m |
| 下台阶 | 0.12 m |
| 上坡 | 20° |
| 下坡 | 18° |
| 横坡 | 12° |
| 沟槽宽度 | 0.10 m |
| 地面粗糙度 | 0.06 m |
| 最小通行宽度 | 0.65 m |
| 最低地形置信度 | 0.70（通用模型/连接段；星玑3D同图综合门槛默认不检查） |

实测17 cm只作为机械极限证据。连续楼梯、负载、材质和下楼验证完成前，不能把软件产品上限提高到17 cm。

## 建图后直接导航（推荐工作流）

1. 在“建图”页完成同一连续园区区域的采集，确认全局三维点云和二维投影均健康，然后使用统一保存。坡道和安全低台阶应作为同一地图的地面结构一起采集，无需拆成连接段。
2. 打开“导航”页，选择这张地图并加载；在前端完成粗初始位姿和三维定位精修。
3. 设置普通单点或多点目标。全局规划会使用保存三维PCD生成并随地图一起校验的地形代价；页面会实时显示当前全局规划路径，实时监督器会根据前方点云自动切换普通、粗糙、低障碍或坡道模式。
4. 始终观察“自动地形导航”状态卡。出现观测过期、未知地形、模式切换失败、超限坡/台阶、坑洞或临边时，最终速度仲裁器会停车，而不是退回不受保护的二维导航。
5. 只有连续楼梯、跨地图/跨独立定位区域或超过自动18°/12 cm边界且已完成专项验收的通道，才进入“园区导航”配置人工连接段。

## 在前端配置高风险例外

不再需要复制 JSON 或修改启动参数。按以下顺序操作：

1. 在“建图”页完成一张地图的建图和统一保存；只有相互独立、无法共享可靠定位坐标系的区域才需要保存成不同地图。
2. 打开“园区导航”，等待“ROS2 已连接”和导航模式启动完成，点击“配置园区”。
3. 先在“建图后直接导航”区确认自动总开关和允许模式；连续楼梯不会出现在自动模式白名单中。只有确需例外时，才在“区域/楼层”中选择地图并建立连接段。
4. 新建连接段，选择起点区域和终点区域。机器人停在连接入口，加载起点区域地图并完成定位后采集起点；再遥控到出口、加载终点区域地图并完成定位后采集终点。
5. 可将当前实时地形观测填入连接段，随后核对水平距离、高差、坡度、台阶、净宽和置信度。只有完成多次实测与安全验收后才勾选“已实地标定”。

### 真实高度约束地面与缓存

星玑 3D 对每帧点云读取同采集时刻 `odom → livox_frame` 的真实三维 TF，不使用高度被强制置零的 `/Odometry`。地面平面在雷达位置的高程必须与“真实雷达高度减安装离地高度”相符，最大误差 0.15 m；缺 TF 或偏差过大保持未知，不允许将屋顶平面写入近期地面缓存。整块平台没有内部边缘时，也按与高度基准的差值保留台阶高度，超过自主 12 cm 上限不能按普通平地放行。
